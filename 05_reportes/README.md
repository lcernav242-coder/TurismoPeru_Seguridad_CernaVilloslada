# Reportes

Esta carpeta contiene la documentación y los archivos correspondientes al reporte analítico del proyecto.

El reporte debe analizar información relacionada con:

- Clientes.
- Reservas.
- Pagos.
- Estados de reserva.

Los principales indicadores considerados son:

- Total de clientes.
- Total de reservas.
- Total de ingresos.
- Ticket promedio.

El reporte final será generado en formato PDF.
